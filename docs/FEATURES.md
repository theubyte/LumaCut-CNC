# LumaCut Feature-Roadmap

## P0 – sichere Basis
grblHAL USB/LightBurn, SKR Mini MZ Pinmap, externe Laser-Interlocks, E-Stop, Z-Home, XY-Home, verifizierte Stepper-Einstellungen, Rücksicherung.

## P1 – Bedienung / Werkstück
Waveshare Touch-Dashboard, unabhängige Befehlsarbitration, Werkzeug-Nullpunkt, mechanischer Taster mit konfigurierbarem X/Y- und Z-Offset, sicherer Autofokus, dokumentierte Materialsätze, jog mit Softlimits.

## P2 – Präzision
XY-Raster, Höhenkarte, kontrollierte Z-Kompensation, Kontrast-/Kantenkamera und Fiducial-Kalibrierung, wiederholbare Motivpositionierung; automatische Z-Fehlerkorrektur nur mit Realzeit-Performance-Nachweis.

## P3 – Erweiterungen
Motion-/Vibrationssensor, Temperaturkompensation, Werkzeugerkennung, Abluftfeedback, Air-Assist, Laserleistungskurve, Wartungsmonitor, Diagnose, Jobsimulation, Fehlerstatistik, Materialoberflächenerkennung.

Jedes Feature: Spezifikation → Mess-/Testkriterien → Pull Request → Versionshinweis → Build → physische Abnahme. Keine Funktion gilt durch Eintrag in dieser Datei als implementiert.
